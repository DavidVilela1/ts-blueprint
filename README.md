# TSBlueprint

Live, interactive diagrams and documentation of the interfaces and type models in the TypeScript file you're editing.

## Usage

Open a `.ts` or `.tsx` file and click the **Open Blueprint** button in the editor title bar (or run `TSBlueprint: Open Blueprint` from the Command Palette).

## Privacy

TSBlueprint does not collect, store, or transmit any personal data or source code. All AST parsing happens locally inside the user's IDE. See [PRIVACY.md](PRIVACY.md).
